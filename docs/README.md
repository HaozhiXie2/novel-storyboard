## 阅读时注意

GitHub 仓库提供代码、说明与示例，不包含已部署的 Python 环境、Dreamina CLI、模型、登录状态或完整生成素材。下载仓库后需要按使用路径配置环境。

即梦工作台已经验证的是单镜头闭环。本地模型分支的时长选项、结构化人物设定或示例输出，都不代表已完成高质量 90 秒短剧自动化、跨镜头锁脸或配音字幕。
