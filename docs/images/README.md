## 更新规则

1. 使用实际运行界面和已有可公开样例，不为了截图偷偷触发付费生成。
2. 不包含凭据、账号余额、私人正文、本机个人目录或未授权素材。
3. 优先覆盖同主题文件名；同步修改截图日期、说明和引用。
4. 在 GitHub 检查图片可加载且文字可读；运行 `python scripts/check-repo.py` 检查相对链接和文件。
5. 不上传模型、大量素材或整段视频；普通截图尽量控制在 2 MB 以内。
