# 小说 → 分镜

输入：用户粘贴的正文，或 `source/` 下的文件。  
输出：`output/<slug>/` 下四份加版权备忘。  
不要出图、不要出视频、不要访问小说网站。

`<slug>` 用书名或章节名的拼音/英文短横线，例如 `chapter-01`。

## Workflow

```
- [ ] 0. 确认来源（无正文则停止）
- [ ] 1. 00-rights.md
- [ ] 2. 01-summary.md
- [ ] 3. 02-bible.md
- [ ] 4. 03-storyboard.md
- [ ] 5. 04-prompts.md
```

改前面的文件后，后面的必须重写，不要留过期分镜。

## 0. 来源

有正文才继续。来源只能是对话粘贴或 `source/`。禁止用搜索/浏览器去「找这本书」。

来源记录应包含原文件名（如有）、用户声明的授权类型、改编范围和处理日期。长章节按完整场景切分，并复用上一段的 `02-bible.md`，保持人物外形、场景和时间线一致。

## Templates

### 00-rights.md

```markdown
- 来源：
- 用户声明：有权用于改编 / 自写 / 公版（择一，按用户说法记录）
- 范围：本章 / 本摘录
```

### 01-summary.md

```markdown
# 剧情摘要

- 一句话：
- 本章节拍（3–7 条，因果清楚）：
- 结尾落到：
- 改编取舍：哪些内心戏改成可见动作
```

### 02-bible.md

```markdown
# 设定

## 人物
| 名 | 身份 | 外形锚点（稳定、可进提示词） | 本章目标 | 关系 |

## 场景
| 名 | 时间 | 空间要点 | 气氛 |

## 锁定事实
本章不可改的情节/身份/结局。
```

### 03-storyboard.md

一场可含多镜。默认一场 3–8 镜，不要把整章压成一镜。

```markdown
# 分镜

## 场 1 · <地点> · <日/夜>
- 本场任务（读者必须知道什么）：
- 情绪走向：

### 镜 1
- 景别：大远 / 全 / 中 / 近 / 特写
- 画面：
- 人物动作：
- 对白 / 旁白 / 内心（内心尽量改成可见）：
- 声音：
- 连续性：接上场/上镜的什么
```

景别、运镜、动作链要写具体，方便以后接漫剧模型。不要写「氛围很好」这类空话。

### 04-prompts.md

每个镜头一组。生图和生视频分开。中文正文可保留；提示词用中英皆可，但同一人物外形锚点必须和 bible 一致。

```markdown
# 提示词

## 镜 1
**生图：** 主体, 外形锚点, 场景, 景别, 光线, 构图, 风格（固定一套，全片重复）
**生视频：** 起始画面摘要；运镜；动作时长感；不要新增角色
**负面：** 变形脸, 多余手指, 字幕乱码, 换装
```

每个镜头还应尽量标明画幅比例、镜头时长、运镜方式和人物一致性锚点。全片只使用一个风格句，并在每个镜头复用。

全片只用一个风格句（例如「国漫赛璐璐、干净线稿、电影布光」），写在文件开头，每镜复用。

## 禁用

- 抓取或补全用户没提供的章节
- 调用生图/生视频 API、下载模型、打开付费网站生成
- 把组件库教程或无关开源项目写进产出
- 一次丢出无法拍摄的文学赏析（那不是分镜）
