# 分镜

## 场 1 · 旧车站 · 傍晚
- 本场任务（读者必须知道什么）：林岚独自在雨中等车，并发现异常物件。
- 情绪走向：冷清 → 警觉。

### 镜 1
- 景别：大远景
- 画面：旧车站被雨幕包围，林岚独自坐在站牌下，远处没有车辆。
- 人物动作：她低头看表，抬头望向空荡的轨道。
- 对白 / 旁白 / 内心：无对白；钟声敲响七下。
- 声音：雨声、远处风声、钟声。
- 连续性：建立车站和雨夜时空。

### 镜 2
- 景别：近景
- 画面：长椅下露出一支亮着红灯的录音笔，水珠落在笔身上。
- 人物动作：林岚伸手捡起录音笔，指尖停顿片刻后按下播放键。
- 对白 / 旁白 / 内心：录音：“别去桥那边。”
- 声音：录音的电流杂音压过雨声。
- 连续性：红色指示灯成为下一场的视觉线索。

## 场 2 · 雨中桥 · 入夜
- 本场任务（读者必须知道什么）：警告真实存在，但林岚选择继续追查。
- 情绪走向：警觉 → 决绝。

### 镜 3
- 景别：全景
- 画面：桥面延伸进黑暗，路灯从近到远一盏接一盏熄灭。
- 人物动作：林岚站在桥头，握紧录音笔。
- 对白 / 旁白 / 内心：无对白。
- 声音：灯灭的电流声、越来越近的雷声。
- 连续性：接上镜 2 的红灯和警告。

### 镜 4
- 景别：中近景
- 画面：林岚把录音笔收进帆布包，迎着雨走向最后一盏灯。
- 人物动作：她抬起风衣领口，脚步不停。
- 对白 / 旁白 / 内心：无对白；保留脚步声作为决心的可见替代。
- 声音：鞋踩积水声、雨声，音乐在结尾留下悬念音。
- 连续性：以背影进入黑暗，为下一章留悬念。
