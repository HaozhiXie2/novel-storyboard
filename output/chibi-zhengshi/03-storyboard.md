# 分镜

统一建议：2.39:1 宽银幕；国风历史战争写实、低饱和青灰与火焰橙对比；不使用《三国演义》戏剧化虚构台词，台词仅取用户提供史料中的核心语义。

## 场 1 · 夏口江岸 · 冬日黄昏
- 本场任务（读者必须知道什么）：曹操已得荆州，刘备退至夏口，江东援军成为生死关键。
- 情绪走向：败退 → 等待。

### 镜 1
- 景别：大远景
- 画面：江雾中的夏口营地，疲惫士卒和密集难民沿江岸移动，远处北方船影压过水面。
- 人物动作：刘备站在高地回望江面，关羽水军船队从雾中掠过。
- 对白 / 旁白 / 内心：旁白：“曹公得荆州，水陆俱下。”
- 声音：江风、橹声、低沉鼓点。
- 连续性：建立曹军压境和刘备孤立处境。

### 镜 2
- 景别：近景
- 画面：鲁肃在湿透的地图上指出江东、荆州和赤壁三处位置。
- 人物动作：他将一枚吴军令牌推向刘备阵营。
- 对白 / 旁白 / 内心：鲁肃：“莫若遣腹心使自结于东，共济世业。”
- 声音：竹简展开声、远处急促脚步。
- 连续性：把逃亡转入结盟行动。

## 场 2 · 柴桑议事厅 · 夜
- 本场任务（读者必须知道什么）：孙权必须在迎降与抗战之间选择，周瑜给出可执行的抗战依据。
- 情绪走向：群臣恐惧 → 主君决断。

### 镜 3
- 景别：中景
- 画面：曹操书信摊在案上，“八十万水军”字样压住地图，群臣神色动摇。
- 人物动作：孙权抬眼，诸葛亮立于灯影边缘，鲁肃沉默不退。
- 对白 / 旁白 / 内心：诸葛亮：“若不能当，何不案兵束甲；若能抗衡，便不可迟疑。”
- 声音：烛火爆裂，厅外风声。
- 连续性：承接镜 2 的联盟议题。

### 镜 4
- 景别：近景
- 画面：周瑜以木筹分开曹军北方士卒、荆州降众和吴军水域。
- 人物动作：他逐一按住“疲”“病”“不习水战”三枚木牌。
- 对白 / 旁白 / 内心：周瑜：“舍鞍马，仗舟楫，与吴越争衡，本非中国所长。”
- 声音：木筹落案声，音乐节拍变得坚定。
- 连续性：将恐惧转化为可计算的战术判断。

### 镜 5
- 景别：特写
- 画面：孙权拔刀斩断案角，碎木飞落，刀锋映出火盆。
- 人物动作：孙权起身，众人同时抬头。
- 对白 / 旁白 / 内心：孙权：“孤与老贼，势不两立。”
- 声音：木案断裂声，鼓点第一次明确落下。
- 连续性：抗曹决策完成，进入备战。

## 场 3 · 赤壁江面 · 冬夜至拂晓
- 本场任务（读者必须知道什么）：黄盖利用曹军连船和东南风完成火攻，孙刘联军扭转战局。
- 情绪走向：试探 → 爆发 → 崩溃。

### 镜 6
- 景别：全景
- 画面：北岸曹军船舰首尾相接，南岸吴军在夜色中列阵，江面被雾切成两半。
- 人物动作：周瑜举旗，黄盖在前锋船上回望火种。
- 对白 / 旁白 / 内心：黄盖：“今寇众我寡，可烧而走也。”
- 声音：水声、绳索绷紧声、压低的号角。
- 连续性：镜 4 的战术分析落实为具体船阵。

### 镜 7
- 景别：中近景
- 画面：十艘蒙冲斗舰装满枯柴、裹着帷幕，旌旗在东南风中猎猎作响。
- 人物动作：黄盖抬手示意，火油沿船舷流下。
- 对白 / 旁白 / 内心：无新增对白；以船上将士互相点头表现决心。
- 声音：风声增强，火石轻响。
- 连续性：保持黄盖老将形象与火攻道具一致。

### 镜 8
- 景别：大远景
- 画面：黄盖船队驶向曹营，北岸士卒探身观望，误以为吴军来降。
- 人物动作：黄盖举旗，前船突然同时起火。
- 对白 / 旁白 / 内心：远处曹军喊声：“黄盖降焉！”随后被火声吞没。
- 声音：群喊、风啸、第一声爆燃。
- 连续性：诈降完成，火攻进入不可逆阶段。

### 镜 9
- 景别：全景
- 画面：火船如箭冲入连环船阵，火焰沿船索蔓延至岸上营落，烟炎张天。
- 人物动作：周瑜率轻锐船队紧随火势推进，曹军士卒跳水逃散。
- 对白 / 旁白 / 内心：无；用雷鼓大进替代解释。
- 声音：雷鼓、木船断裂、燃烧和落水声。
- 连续性：镜 8 的东南风必须持续，火势方向统一向北岸延伸。

## 场 4 · 华容道 · 战后拂晓
- 本场任务（读者必须知道什么）：曹操败退，赤壁改变南北力量格局，但战争并未结束。
- 情绪走向：混乱 → 惨烈余波 → 暂时收束。

### 镜 10
- 景别：中远景
- 画面：泥泞山道被车马踩成深沟，曹军残部在狂风中搬草填路。
- 人物动作：曹操骑马回望，羸兵跌入泥中，后方追兵鼓声隐约传来。
- 对白 / 旁白 / 内心：旁白：“道不通，悉使羸兵负草填之，骑乃得过。”
- 声音：马嘶、泥水声、喘息和远鼓。
- 连续性：从赤壁火光切到灰冷拂晓，色彩反转。

### 镜 11
- 景别：大远景
- 画面：曹操残军消失在北方山口，江陵城与赤壁江面分处画面两端。
- 人物动作：刘备与周瑜的水陆军队沿江推进，镜头停在未熄的烟线上。
- 对白 / 旁白 / 内心：旁白：“曹仁等守江陵，曹操引军北还。”
- 声音：风声渐弱，留下低沉持续音。
- 连续性：明确战役胜负与后续荆州争夺的悬念。
