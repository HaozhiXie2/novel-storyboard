# 原文与私人材料

这里保留可以公开的示例原文，例如 [虚构章节](example-chapter.md)。只有确认可以公开的文本才提交到本目录。

自己的未公开章节、私人稿件或只有改编许可但没有公开原文许可的材料，默认放在 `source/private/`。该目录已被 Git 忽略；使用 Agent 时明确指定输入文件，并让私人交付包写入 `output/private/<slug>/`。

文件建议使用 UTF-8 TXT / MD、稳定名称，例如 `chapter-01.md`。不要把爬来的整本网文放进来；工作流只处理用户主动提供且有权使用的正文。

忽略规则不清除已经提交的历史。公开示例须同步填写来源与权利说明，见 [权利模板](../rights/RIGHTS_TEMPLATE.md) 和 [目录规范](../docs/PROJECT_STRUCTURE.md)。
